Настройки для начала

«Растянуть», масштаб 100%, «Пиксель в центре», чёрный фон и 8 кадров/с. Именно эти настройки показаны на карточках. Для длинных GIF в JSON берутся первые восемь секунд; сам GIF скачивается целиком. Размер и положение можно изменить в конструкторе.

Исходники принадлежат их авторам. На карточках есть оригинальные названия, источники и ID авторов из LaMetric либо имя автора GitHub. JSON — автоматическое преобразование того же файла в RGB-кадры.
