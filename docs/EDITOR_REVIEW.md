# Проверка удобства редактора — версия 1.4

Редактор проверен на сценариях: выбрать шаблон, править кадр, менять яркость, дублировать, создавать с нуля, ставить предпросмотр на паузу, открыть редактор снова, задать таймер и сохранить проект.

| Проблема до изменения | Причина | Что изменено |
|---|---|---|
| Выбор шаблона не менял рисунок | Требовалась отдельная кнопка открытия | Выбор сразу открывает шаблон, кнопка осталась для повторного открытия оригинала |
| Новый кадр или яркость возвращали сердце | Данные брались из Layer 1 | Новый кадр копирует текущий, яркость работает с его цветами |
| На паузе терялось место | Показ возвращался к выбранной карточке | Сохраняются точные цвета, время и карточка; есть продолжение |
| После открытия снова первый кадр | Сохранялся проект без состояния просмотра | Отдельно сохраняются кадр, позиция и выбор клавиш |
| Заливка четырёх клавиш меняла область анимации | Одно выделение использовалось для двух задач | В своих кадрах выбор для рисования отделён от области воспроизведения |
| Карточки цветов не объясняли рисунок | Показывались первые семь клавиш | Теперь показана миниатюра всей клавиатуры |
| Маленькое окно запускало сердце вместо проекта | В списке не было timeline | Проект из конструктора поддерживается, кадры и область сохраняются |
| Остановка всегда возвращала Layer 1 | Был один вариант восстановления | Три явных режима, по умолчанию последний кадр остаётся |
| Язык было трудно найти | Выпадающее меню | Две кнопки RU / ENG с выделением активной |

## Проверено

- Автоматические тесты редактора: сохранение кадров при чтении источника и запуске, яркость, копирование, пауза, изменение таймера, повторное открытие, отдельный выбор для рисования и анимации.
- HID-симулятор: все варианты остановки пишут только Layer 2, данные Layer 1 сохраняются.
- Браузер: готовый шаблон, новый проект WASD, заливка двух кадров, пауза, языки, таймер и библиотека. Скриншоты этой проверки используются в гайде.

## Практические ограничения

Заливка требует сначала выбрать клавиши, затем нажать кнопку. Это не кисть для рисования одним движением. Частичная анимация сознательно берёт фон из Layer 1; это пояснено счётчиком области и гайдом. Одновременно редактировать один черновик в нескольких окнах не рекомендуется: библиотека и JSON подходят для независимых проектов. Физический результат на конкретной клавиатуре требует отдельной проверки.
